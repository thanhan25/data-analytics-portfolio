## 🛠️ Project Index

### 1. [Trade Performance Auditor & ETL Pipeline ↗](https://github.com/thanhan25/trade-performance-auditor)
* **Core Track:** Data Engineering & Database Architecture
* **Tech Stack:** Python, SQL (SQLite), PEP 517 Package Structures, GitHub Actions CI/CD
* **The Solution:** Engineered an end-to-end automated ETL pipeline designed to ingest, structurally clean, and validate high-frequency transactional data. Built strict relational SQL database schemas with primary/foreign key integrity, optimized data retrieval speeds to $O(\log n)$ efficiency via strategic B-Tree indexing on core asset parameters, and enforced a 90.91% verified unit testing gate.
* **Key Skills Proved:** Relational database design, data cleaning, automated pipelines, context-managed database sessions, test-driven development.

### 2. [Retail Media CLV Optimizer ↗](https://github.com/thanhan25/retail-media-clv-optimizer)
* **Core Track:** Data Science & Customer Analytics
* **Tech Stack:** Python, BG/NBD Models, Gamma-Gamma Frameworks, Google Cloud Platform (BigQuery)
* **The Solution:** Developed an advanced predictive analytics engine designed to model and optimize Customer Lifetime Value (CLV) for retail media environments. By implementing probabilistic BG/NBD and Gamma-Gamma models, the system tracks and forecasts customer transaction frequencies, churn risks, and future monetary value distributions to maximize marketing ROI, backed by a live cloud data pipeline integration with Google Cloud BigQuery.
* **Key Skills Proved:** Probabilistic modeling, predictive analytics, statistical machine learning, cloud data warehousing, defensive schema mapping.

### 3. [Pricing A/B Testing Simulator ↗](https://github.com/thanhan25/pricing-ab-simulator)
* **Core Track:** Quantitative Economics & Statistical Inference
* **Tech Stack:** Python, Statistical Hypothesis Testing, Causal Inference, Power Analysis
* **The Solution:** Built a rigorous simulation and evaluation framework for pricing-focused A/B tests. Leveraging advanced econometric and statistical mechanics, the engine runs hypothesis testing, calculates optimal sample sizes via power analysis, and evaluates price elasticity and treatment effects to drive data-backed strategic pricing decisions using defensive verification constraints.
* **Key Skills Proved:** A/B testing design, statistical inference, hypothesis testing, causal inference, economic modeling.

### 4. [Invoice LLM Intelligence & Fine-Tuning Pipeline ↗](https://github.com/thanhan25/invoice-llm-pipeline)
* **Core Track:** Generative AI Infrastructure & Data Engineering
* **Tech Stack:** Python, Token-Aware Extraction, Schema Invariant Constraints, Dataset Curation for SFT
* **The Solution:** Designed an automated context-conditioning and text-parsing pipeline converting multi-format corporate invoices (PDFs, scans) into schema-validated data arrays. Implemented token-aware sliding-window character segmentation to prevent text-clipping boundaries and built automated curation routines that filter and package raw text into clean, structurally valid `.jsonl` pairs optimized for downstream LLM fine-tuning.
* **Key Skills Proved:** Prompt-response data engineering, text chunking optimization, structural schema validation, dataset compilation for fine-tuning, automated code compliance pipelines.
